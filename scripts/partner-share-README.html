Partner Deployment Guide (GKE + Helm)

This folder contains scripts and chart files to deploy, validate, and destroy POS Validation SDK on Google Kubernetes Engine.

Prerequisites

Install these commands before running scripts:

  • gcloud
  • kubectl
  • helm
  • curl
  • dig (or nslookup)

Google Cloud authentication is required.

For testing, you can use a new Google Cloud trial account/project. Google Cloud commonly offers up to $300 in free trial credits for eligible new users.

Deploy

./partner-deploy-gcp.sh

This script:

  • Checks prerequisites and active gcloud auth
  • Reuses saved config defaults (Enter accepts default)
  • Deploys Helm release
  • Shows static IP for DNS A record setup
  • Waits for DNS confirmation
  • Applies ingress + managed certificate
  • Saves deployment-config.env and deployment-state.env

Check

./partner-check-gcp-deployment.sh

This validates cluster, deployment, ingress/certificate, DNS mapping, and HTTPS health endpoint.

Destroy

./partner-destroy-gcp.sh

Removes Helm release, namespace resources, cluster, static IP, and optional DNS record. It auto-loads values from saved local files, so values usually do not need to be re-entered.
